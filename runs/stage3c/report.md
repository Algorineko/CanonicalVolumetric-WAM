## 已确立的表示规律(seed42)

1. **free-space 信息不可省**:P2E > P2 在全部非退化预算(clean 0.01: 0.102 vs 0.085;0.02: 0.473 vs 0.441)——free 射线样本(体素 free 通道的点云等价物)带来一致增益。
2. **匹配 falseOcc 实测点对比(default 行,thr=0,clean_test)**:P1-V dynIoU 0.379 @ fo 0.0064;P2E **0.465** @ fo 0.0086;P3 **0.476** @ fo 0.0071 → 在实际可用的操作区(fo≈0.007–0.01),带 free-space 的点/视图表示**持平或略优于体素**。
3. **极严格预算(0.005)只有体素给出非退化点**(P1-V 0.269 vs 点/视图 ≈0)——但这主要是校准迁移问题(点模型的 free-logit 分布 val→test 偏移更大,0.01 预算阈值在 test 上退化到 fo≈0),尚不能定论为容量缺陷;校准对齐后需复测。
4. **Clean→Rand 泛化缺口三表示同量级**(default: 0.46→0.40)——泛化差异主要来自数据不是表示。
5. P3(per-view pointmap)与 P2E 打平且显存最高(2.75 vs 1.55GiB)——本任务尺度下视角结构无额外优势。

## 表示终审

**倾向 + 待确认**:匹配点对比中 P2E/P3 ≥ P1-V(0.02 与 default 处),极严格预算体素独活;体素额外保留 unknown/visibility 语义(可见性头 rev_acc 0.95)。待 P1-V 三 seed 出齐 + P2E 校准对齐复测后定稿。**当前证据不足以宣称"体素不可替代"**——这正是审查方"不预设体素胜出"的验证价值。
